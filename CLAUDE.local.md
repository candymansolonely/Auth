# CLAUDE.local.md

Private, per-developer notes for Claude Code. This file is gitignored — use it for
local environment quirks, personal shortcuts, or in-progress context you don't want
checked into the shared `CLAUDE.md`.

Examples of what belongs here:
- Local connection strings / ports that differ from the team defaults
- Personal debugging notes while working on a feature
- Temporary reminders that don't belong in the shared project memory
